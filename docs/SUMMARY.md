# 10分スケジュール：要点まとめ

## どんなアプリか
- 1日を**10分刻み**（1日144マス）で管理する予定表
- **インストール不要**。スマホ・PCのブラウザで動く
- **招待リンクを送るだけ**で仲間と共有できる。ログインもいらない

## 主な機能
- **表示**
  - 縦が時間、横がメンバーの表。時刻とメンバー名はスクロールしても固定
  - 現在時刻の赤線、マス目の大きさの切り替え（小・標準・大）
- **予定の入力**
  - スマホは開始マス→終了マスの2回タップ、PCはドラッグ
  - 入力画面で、タイトル・担当メンバー・時刻・リマインドを設定
  - 同じ人の予定が重なると保存できず、理由が表示される
- **メンバー管理**：名前・色の変更、追加、削除。「全体」の列を作って全員の予定を入れる使い方もできる
- **共有**
  - 誰かが入力すると、5秒ほどで全員の画面に反映
  - 左上の表示で状態が分かる（「共有中」＝緑、「接続待ち」＝オレンジ）
- **通知**：開始の5〜60分前にお知らせ。「自分の予定だけ」に絞れる
- **印刷**
  - A4（縦・横）の画像にして保存・印刷
  - 人数が多いと自動でページを分ける（1ページに縦6人・横10人まで）

## 使っている仕組み（費用はすべて無料枠）
- **公開先**：GitHub Pages（https://dreamkoshien0215-ui.github.io/test/）
- **データの保存先**：Firebase のプロジェクト「tenmin-schedule」
- **月額費用**：0円。無料枠を超えても止まるだけで、勝手に課金されることはない

## 自分の予定表
- リンク：https://dreamkoshien0215-ui.github.io/test/?b=KIqjUFvHIqa52Z2ANi77
- **このリンクをなくすと戻れない。** ホーム画面への追加や、LINE の自分用トークへの保存をしておく
- トップページ（`…/test/` だけのURL）を開くと、別の新しい予定表ができてしまう

## 知っておきたい制約
- リンクを知っている人は、**誰でも閲覧・編集・削除**ができる。仲間内だけで共有する
- 誰が入力・変更したかの記録はない
- 通知は**ページを開いている間だけ**。iPhone では画面内にお知らせが出る
- 「👥 メンバー」で ✕ を押すと、その人の予定もすべて消える

## これまでに直した主な不具合
- **予定がサーバーに届いていなかった問題**
  - 「共有中」と出ているのに、予定がスマホの中にしか保存されていなかった
  - 通信のしかたを変えて解決。保存できなかったときは、必ず画面に表示される
- **人数が多いときの印刷**：名前がはみ出す問題を、ページ分割と文字の省略で解決
