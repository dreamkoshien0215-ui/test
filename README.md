# 10分スケジュール

1日を10分単位で管理し、複数人で共有できるブラウザ向けスケジュールツールのプロトタイプです。

- **試す**: `index.html` をブラウザで開くだけ（インストール不要）
  - PC: 空きマスをドラッグして予定を作成
  - スマホ: 開始マス → 終了マスの順にタップして予定を作成
  - 予定をクリック/タップで編集・削除、「👥 メンバー」で列を追加
  - 「🔔 通知を許可」でリマインド通知（ページを開いている間）
- **設計メモ**: [docs/DESIGN.md](docs/DESIGN.md)（要件整理・技術構成・UI・通知方針・本番化手順）

現在はデータをブラウザ内（localStorage）にのみ保存します。同じブラウザの別タブには即時反映されますが、他の端末とは共有されません。
